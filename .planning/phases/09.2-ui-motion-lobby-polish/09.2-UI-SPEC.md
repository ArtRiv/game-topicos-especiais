# Phase 09.2 — UI Design Contract

> Visual and interaction contract for the cinematic pre-match flow (Splash → MainMenu → Lobby → LOADING → COUNTDOWN). All values derive from `09.2-CONTEXT.md` D-01..D-15. This is a Phaser 3.87 game canvas, not a DOM/web UI — shadcn does not apply.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Phaser 3.87 canvas renderer) |
| Preset | not applicable |
| Component library | none — Phaser scene-graph primitives (BitmapText, Image, Video, Rectangle, Camera) |
| Icon library | none (pixel-art atlas-only project; no glyph/icon font) |
| Font | `Press_Start_2P` BitmapText atlas at `assets/fonts/Press_Start_2P/press_start_white-2.{png,xml}` (white glyph fill, tinted at draw time per Phase 9.1-04 standard) |

**Hard rule (carried from Phase 9.1-04):** every pixel-art text element in this phase MUST be `BitmapText`. No `Phaser.Text + setResolution(N)` is permitted, even when porting UI-branch scenes (see CONTEXT.md D-02 "CONVERT during port").

## Spacing Scale

Phaser canvas measures in pixels. Scale stays on the BitmapText 8-pixel grid (atlas glyph cell = 8px) per Phase 9.1-04.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Typewriter caret pad, sub-line lift |
| sm | 8px | Inline gap between BitmapText runs |
| md | 16px | Tip-card inner padding, map-preview-to-text gap |
| lg | 24px | Vertical gap between cinematic beats (map name → preview, preview → info) |
| xl | 32px | Section break above tip card |
| 2xl | 48px | Title-to-subtitle gap in MainMenu cinematic |
| 3xl | 64px | Top/bottom safe-zone insets from canvas edge |

**Menu-item vertical stride:** `MENU_SPACING = 26px` (NON-multiple-of-4 exception, inherited verbatim from UI-branch `main-menu-scene.ts` to preserve the existing cinematic stagger feel — CONTEXT.md "Reusable Assets / arriving via UI port"). Document in code with a comment; do not "fix" to 24 or 32 — the cinematic was hand-tuned at 26.

**Exceptions:**
- `MENU_SPACING = 26` (main-menu item stride, see above).
- BitmapText size choices snap to multiples of 8 (atlas cell), not 4 (Phase 9.1-04 atlas constraint, CONTEXT.md Claude's Discretion).

## Typography

All sizes are BitmapText render heights in pixels. Atlas is monochrome white; we tint via `setTint(0xRRGGBB)` at draw time.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 32px | pixel (single weight) | 1.25 | MainMenu title `HIGH FANTASY`, LOADING map-name typewriter |
| Heading | 16px | pixel | 1.25 | MainMenu subtitle `- ONLINE EDITION -`, LOADING map-info first line |
| Body | 16px | pixel | 1.5 | LOADING map-info body, tip-card body, menu items (`CRIAR LOBBY` etc.) |
| Label | 8px | pixel | 1.5 | Splash "PRESS ANYTHING..." sub-hint lines, footer credit |

**BitmapText weight note:** Press_Start_2P is a single-weight pixel font. There is no "regular vs. semibold" axis. Emphasis comes from **size + tint**, not weight. (Satisfies the spirit of the "2 weights max" rule — we declare exactly **one** weight because the medium does not support more.)

**Line-height enforcement in Phaser:** BitmapText does not auto-apply line-height. When stacking multi-line strings, compute `y_offset = size * line_height` between lines manually (helper recommended in planner output).

**Tint palette by role:**

| Role | Tint | Hex |
|------|------|-----|
| Display | white | `0xFFFFFF` |
| Heading | parchment | `0xE8D9A8` |
| Body | white | `0xFFFFFF` |
| Body (de-emphasised, e.g. tip-card body) | muted-grey | `0xB8B8B8` |
| Menu item idle | white | `0xFFFFFF` |
| Menu item hover | accent gold | `0xFFC857` |
| Splash blinker | white at alpha-pulse | `0xFFFFFF` α 0.3↔1.0 |

## Color

This phase is a dark cinematic theme. Colors below are canvas fills / `setTint` values, not CSS.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `0x000000` (pure black) | Splash background, fade-to-black transitions, LOADING canvas backdrop, vignette base |
| Secondary (30%) | menu video (`landscape.mp4`) under `0x000000 α 0.4` vignette | MainMenu background — UI-branch asset rendered with LINEAR filter to avoid pixelArt smear (CONTEXT.md D-06) |
| Accent (10%) | `0xFFC857` (gold) | **Reserved for:** menu-item hover state ONLY |
| Destructive | not used | No destructive actions in this phase |

**Accent reserved for (explicit list — accent must NEVER appear on any element not in this list):**
1. MainMenu item hover tint (`CRIAR LOBBY`, `ENTRAR EM LOBBY`, `CONTA`, `OPCOES`, `CREDITOS`, `SAIR`).

**No accent on:** title, subtitle, splash text, LOADING typewriter text, tip card, map name, map info, footer.

**Tip-card surface:**
- Background: `0x0A0A0F` (near-black with hint of cool tint) at α 0.85.
- Border: 1px stroke `0x2A2A35` (subtle, no glow).
- No drop shadow (pixel-art aesthetic).

**Vignette overlay (MainMenu over video):** `0x000000` at α 0.4, full-canvas rectangle, rendered above video, below text. Inherited from UI-branch (CONTEXT.md D-06).

## Motion & Interaction Contract

This is the load-bearing section for 9.2. All durations and easings are locked.

### Splash Scene

| Beat | Trigger | Effect | Duration | Easing |
|------|---------|--------|----------|--------|
| Idle | scene.create | "PRESS ANYTHING..." blinks via α tween 0.3↔1.0 | 800ms per cycle, looping | `Sine.InOut` |
| Dismiss | any pointer or key | `cameras.main.fadeOut(400, 0, 0, 0)` → on `FADE_OUT_COMPLETE` → `scene.start(MAIN_MENU_SCENE)` | 400ms | (camera built-in) |
| Music preload | scene.create | `MusicManager.instance.loadTracks(this)` | — | — |

### Main Menu Cinematic (first-visit only; gated by module-level `cinematicPlayed` flag)

| Beat | t (ms) | Effect | Duration | Easing |
|------|--------|--------|----------|--------|
| Fade in | 0 | `cameras.main.fadeIn(400, 0, 0, 0)` from black | 400 | (camera built-in) |
| Music start | 0 | `MusicManager.instance.playMenu(this)` at vol `0.05` | — | — |
| All UI hidden | 0..2000 | title α=0, subtitle α=0, menu items α=0 | — | — |
| Title slam | 2000 (`MUSIC_DROP_MS`) | scale 1.3 → 1.0 | 250 | `Back.Out` |
| Title alpha | 2000 | α 0 → 1 | 150 | `Linear` |
| Subtitle reveal | 2150 | α 0 → 1, y offset `+8 → 0` | 200 | `Quad.Out` |
| Menu item stagger | 2200 + (i × 60) | per-item α 0 → 1, x offset `-8 → 0` | 200 | `Quad.Out` |

**Subsequent visits (cinematicPlayed === true):** skip the 2000ms hold — title/subtitle/menu items render at final state immediately on `fadeIn`.

### Menu Item Hover/Click

| State | Effect |
|-------|--------|
| Idle | tint `0xFFFFFF`, no scale |
| Hover (`pointerover`) | tint `0xFFC857`, scale 1.0 → 1.05 over 100ms `Quad.Out` |
| Unhover (`pointerout`) | tint `0xFFFFFF`, scale 1.05 → 1.0 over 100ms `Quad.Out` |
| Click (`pointerdown`) | `scene-transition.startScene(this, TARGET_KEY, 300)` → camera fadeOut 300ms then `scene.start` |

### Lobby Start → LOADING Transition (CONTEXT.md D-07..D-09)

| Beat | t (ms) | Effect | Duration | Easing |
|------|--------|--------|----------|--------|
| Eager teardown | 0 | DOM + configBlock destroy (Phase 9.1-03 pattern) — runs synchronously BEFORE the tween starts | — | — |
| Camera fade | 0 | `cameras.main.fadeOut(400, 0, 0, 0)` | 400 | (camera built-in) |
| Music duck | 0 | menu music volume tween `0.03 → 0` in parallel | 400 | `Linear` |
| Music stop | 400 | `MusicManager.instance.stopMenu()` (hard stop, NOT crossfade — CONTEXT.md D-09) | — | — |
| Scene start | 400 | `scene.start(LOADING_SCENE)` on `FADE_OUT_COMPLETE` | — | — |

**Cross-client sync:** each client plays independently. No server protocol event. LoadingScene min-display floor (Phase 7) absorbs ~50ms jitter (CONTEXT.md D-08).

### LOADING Cinematic Beats (CONTEXT.md D-10; ~8000ms total)

Constants declared at top of `loading-scene.ts`:

```ts
const T_MAP_NAME_MS     = 1500;
const T_PREVIEW_FADE_MS = 1000;
const T_MAP_INFO_MS     = 2000;
const T_GAP_MS          = 500;
const T_TIP_CARD_MS     = 2500;
const T_FADE_OUT_MS     = 500;
```

| Beat | t (ms) | Effect | Easing |
|------|--------|--------|--------|
| Map name typewriter | 0 → 1500 | reveal `{MAP NAME}` one char per `T_MAP_NAME_MS / textLength` interval | `Linear` |
| Map preview fade-in | 1500 → 2500 | thumbnail (96×64, scaled ×4 = 384×256) α 0 → 1 | `Quad.Out` |
| Map info typewriter | 2500 → 4500 | reveal 3 info lines, characters distributed over the window | `Linear` |
| Breathing gap | 4500 → 5000 | nothing animates | — |
| Tip card enter | 5000 → 5200 | α 0 → 1, y offset `+16 → 0` | `Quad.Out` |
| Tip card hold | 5200 → 7500 | static | — |
| Fade out | 7500 → 8000 | `cameras.main.fadeOut(500, 0, 0, 0)` → handoff to GameScene/COUNTDOWN | (camera built-in) |
| Gameplay music start | computed: `t = 8000 + COUNTDOWN_TOTAL_MS - GAMEPLAY_MUSIC_DROP_MS` | so the drop lands at COUNTDOWN-end (CONTEXT.md D-14) | — |

**Position contract (Claude's discretion per CONTEXT.md, locked here for executor):**
- Map name: horizontally centered, y = `canvasHeight * 0.20`.
- Map preview: horizontally centered, y = `canvasHeight * 0.40`, rendered at integer scale ×4 (no fractional scaling).
- Map info: horizontally centered, y = `canvasHeight * 0.65`, lines stacked with line-height 1.5.
- Tip card: horizontally centered, y = `canvasHeight * 0.85`, width `min(canvasWidth - 64, 480)`, padding 16px.

### Typewriter Helper Contract (CONTEXT.md D-11)

`src/common/typewriter.ts`:

```ts
function typewrite(
  scene: Phaser.Scene,
  target: Phaser.GameObjects.BitmapText,
  fullText: string,
  durationMs: number,
  onComplete?: () => void
): Phaser.Time.TimerEvent
```

- Uses `scene.time.addEvent` with `delay = durationMs / fullText.length`.
- Each tick appends one character via `target.setText(fullText.substring(0, i))`.
- `Linear` cadence (no easing — characters reveal at constant rate, CONTEXT.md Claude's Discretion).
- No cursor/caret glyph in v1 (omit to keep helper ~40 lines).

### Music Volume Profile (CONTEXT.md D-13)

| Scene/State | Track | Volume |
|-------------|-------|--------|
| SplashScene | menu_music | 0.05 |
| MainMenuScene | menu_music | 0.05 |
| LobbyScene (Connect / Browser / Waiting Room) | menu_music | 0.03 (ducked on `LobbyScene.create()` via `MusicManager.instance.setMenuVolume(0.03)`) |
| Lobby → LOADING transition (400ms) | menu_music | 0.03 → 0 (linear), then stop |
| LoadingScene cinematic onwards | gameplay_music | 0.05 (constant) |
| GAMEPLAY_MUSIC_DROP_MS | constant | 4000 (tunable; computed start delay = `LOADING_TOTAL + COUNTDOWN_TOTAL - 4000`) |
