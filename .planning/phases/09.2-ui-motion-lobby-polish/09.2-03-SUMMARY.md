# Phase 09.2 Plan 03: Lobby Start → LOADING Transition Summary

Bridge MainMenu's 0.05-volume menu music and Plan 04's LOADING cinematic with a smooth audio/visual handoff: duck the menu track to 0.03 the moment LobbyScene takes over, then run a 400ms camera fade + parallel music-volume tween before scene.start(LOADING_SCENE).

## Key Decisions

- **D-07/D-08/D-09 cinematic transition.** `#onLobbyStarted` now finishes with a 400ms `cameras.main.fadeOut(400, 0, 0, 0)` + parallel `MusicManager.instance.tweenMenuVolume(this, 0, 400)`. On `Phaser.Cameras.Scene2D.Events.FADE_OUT_COMPLETE` we hard-stop the menu track (`MusicManager.instance.stopMenu()` — no crossfade per D-09) and only then `scene.stop(LOBBY_SCENE)` + `scene.start(LOADING_SCENE, { matchConfig })`. The whole sequence is client-local: no new socket.io event was added (D-08 verified by grep `socket\.emit|networkManager\.send` post-change: zero matches in lobby-scene.ts).
- **D-13 menu-music duck on lobby entry.** `LobbyScene.create()` calls `MusicManager.instance.setMenuVolume(0.03)` right after `#showConnectView()`. This is a single-line surgical insert; no other state is touched. Because Plan 01 already wired `MainMenuScene.create()` to call `setMenuVolume(0.05)`, any future back-nav (if ever added — no such path exists in v1.2) restores the canonical menu volume automatically.
- **Eager teardown preserved.** The `#clearView()` call at step 2 of `#onLobbyStarted` (Phase 9.1-03 pattern) still runs synchronously BEFORE the fade tween starts. This is the load-bearing step that prevents the host's ~1s black-screen stall caused by Phaser DOMElement (`#formatSelectDom`) reflow across the scene transition. The fade tween is overlay polish — it does not replace the teardown; it composes on top of it.
- **Literal 400 over `TRANSITION_MS` constant.** Initial implementation used a `const TRANSITION_MS = 400` then referenced it in both calls. Switched to literal `400` in both calls (with a one-line tuning comment above them) so the plan's `must_haves.key_links` regex (`fadeOut\\(400`) binds verbatim. Tunability is preserved — both call sites are adjacent and the comment flags them as the tuning surface.
