<objective>
Eliminate the ~1s black-screen stall the host experiences when transitioning LobbyScene -> LoadingScene. The current `#onLobbyStarted` handler stops/starts the scene without first removing the host-only DOM `<select>` element and the `#configBlockObjects` Phaser objects — those are torn down only by the SHUTDOWN handler, which fires AFTER `scene.start()`. For the host, the browser ends up compositing a stale `<select>` DOM node against the freshly-mounted LoadingScene for at least one frame, producing the visible black flash. Non-hosts don't hit this because they never created the DOM `<select>` or the `#configBlockObjects` map cards.

Fix: in `#onLobbyStarted`, run the same teardown logic that `#clearView` runs, BEFORE `scene.start(LOADING_SCENE)`. Make the SHUTDOWN handler tolerant of already-cleaned state (it already is, since `o.destroy()` on a destroyed Phaser GameObject is a no-op and `null`-coalescing handles the DOM ref).

Purpose: Closes UAT gap "host's lobby->loading->game transition is as smooth as the non-host's" (Test 9). Brings host transition smoothness to parity with non-host.

Output: A small reordering inside `#onLobbyStarted` that destroys the host-only DOM element and configBlock objects before the scene transition fires.
</objective>

<!-- Why the black screen happens: -->
Phaser DOMElements live in a parent <div class="phaser-dom-container"> that is OUTSIDE the canvas. When LobbyScene -> LoadingScene runs:
1. `scene.stop(LOBBY)` queues a SHUTDOWN event for next tick
2. `scene.start(LOADING)` mounts LoadingScene IMMEDIATELY
3. LoadingScene's create() runs, painting its scene contents on the canvas
4. The browser's compositor must reflow because the DOM <select> is still in the DOM tree, blocking/delaying the canvas paint by one or more frames
5. SHUTDOWN finally fires, #clearView() destroys the DOM <select>, the next frame composites cleanly

By destroying the DOM <select> BEFORE scene.start, the browser's reflow happens during the still-mounted lobby scene (cheap) instead of overlapping the new scene mount (expensive).
