<objective>
Make the LobbyScene text crisp on all displays. The UAT gap hypothesis was "missing `pixelArt: true`" — but inspection shows `src/main.ts` already declares both `pixelArt: true` and `roundPixels: true`. The actual problem: Phaser's `Text` GameObject rasterizes glyphs to an internal canvas at `resolution = 1` by default; with `pixelArt: true`, that internal canvas is then nearest-neighbor-scaled, producing under-sampled / "blurry-chunky" text on any display whose effective device pixel ratio exceeds 1 (modern laptops, Retina, scaled HiDPI desktops).

Fix: bump every `Phaser.GameObjects.Text` in `LobbyScene` to `setResolution(2)` (or `Math.max(2, window.devicePixelRatio)` for true HiDPI parity). This costs ~4x text-atlas memory per Text object but yields crisp glyph edges.

Purpose: Closes UAT gap 1a (blurry lobby text — cosmetic). Restores the intended pixel-art aesthetic without changing engine config.

Output: Either (a) a small helper `#crispText(...)` that wraps `this.add.text(...)` with `.setResolution(...)` and is used everywhere in LobbyScene, OR (b) explicit `.setResolution(2)` chained onto every `this.add.text(...)` call in LobbyScene. Executor picks based on diff size — helper is preferred for maintainability.
</objective>
